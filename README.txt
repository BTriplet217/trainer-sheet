Trainer Sheet app

1. Upload everything in this folder, keeping the file names, to any web address that starts with https://
   (a folder on your own site, GitHub Pages, Netlify, and so on).
2. On your phone, open that address in Chrome once while online.
3. Chrome menu > Add to Home screen > Install.

After that it opens from the home screen icon with or without signal, and every edit saves on the phone.

Your edits live on that phone, not on the website. Use "Download a backup" at the bottom of the sheet
now and then; "Restore a backup" loads one back in, on this phone or another.

If you ever replace index.html, change the version name at the top of sw.js so phones fetch the new copy.

This copy starts blank. After installing, tap "Restore a backup" at the bottom and pick trainer-sheet-backup.json.
